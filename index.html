Open teaching modules

Computer Graphics Explorables

Interactive, browser-based lessons on the algorithms behind computer images. Each module runs the real algorithm live, lets you step through it one stage at a time, tells its history, and shows how the graphics card makes it fast. Built for self-study and for use in the classroom.

Using these modules

In class

Every module and every part has its own link, for example ray-tracing/#algorithm, or gaussian-splatting/#sh, so you can put a specific step in a slide, syllabus or LMS page. The step-through diagrams work well projected: press Play and narrate.

For self-study

Work through the parts in order with the Next button or the arrow keys. Each part ends with things to try in the live demos.

Offline or locally

Each module is a single HTML file with no build step. Clone or download the repository and open index.html. Fonts, three.js and MathJax load from a CDN; everything else is inline.
